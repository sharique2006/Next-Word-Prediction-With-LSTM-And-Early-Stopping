# Next-Word-Prediction-With-LSTM-And-Early-Stopping

Next Word Prediction using LSTM & Streamlit is a Natural Language Processing and Deep Learning project that predicts the most probable next word based on a given sequence of words.

The model is trained on Shakespeare's Hamlet text and uses TensorFlow/Keras LSTM networks to learn patterns and relationships between words. The text is first cleaned and tokenized, then converted into sequential training data using n-gram sequences. An LSTM-based neural network is trained to predict the next word from the given context.

The trained model is integrated with a Streamlit web application, allowing users to enter a sequence of words and get a predicted next word in real time.

🚀 Key Features
📖 Trained on Shakespeare's Hamlet text
🔤 Text tokenization and preprocessing
🧩 N-gram sequence generation
🧠 LSTM-based deep learning model
🎯 Next-word prediction using Softmax
⏹️ Early Stopping to reduce overfitting
💾 Saved trained model and tokenizer
🌐 Interactive Streamlit web interface
⚡ Real-time next-word prediction
